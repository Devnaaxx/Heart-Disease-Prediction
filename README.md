 Heart Disease Prediction Using Machine Learning

 Project Overview

This project focuses on predicting the presence of heart disease using Machine Learning classification algorithms.

The objective is to train and compare multiple Machine Learning models and identify the model that achieves the highest accuracy on the test dataset.

 Project Objectives

* Analyze heart disease dataset features.
* Prepare the dataset for Machine Learning.
* Train multiple classification models.
* Compare model performance using accuracy.
* Evaluate predictions using a confusion matrix and classification report.

 Dataset Information

* Dataset: Heart Disease Dataset
* Total Records: 303
* Total Features: 13 input features
* Target Column: target
* Total Columns: 14

 Technologies & Libraries

* Python
* Google Colab
* Pandas
* NumPy
* Scikit-learn

 Machine Learning Algorithms

1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Decision Tree Classifier

 Model Performance

Algorithm	Accuracy
Logistic Regression	85.25%
KNN	90.16%
Decision Tree	75.41%

Best Performing Model: K-Nearest Neighbors (KNN)

KNN achieved the highest test accuracy of 90.16% among the three models in this experiment.
